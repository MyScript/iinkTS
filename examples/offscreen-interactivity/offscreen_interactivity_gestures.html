Interactive Ink Editor — Gestures

Gestures

Write normally — the editor detects gestures in the ink stream. Configure each via the ✌️ Gesture menu in the toolbar.

Scratch-out

Scribble rapidly back and forth over content to erase it.

Surround

Draw a closed loop around symbols. Configurable: select, surround, or highlight.

Strikethrough

Draw through content. Configurable: erase it, or apply a strikethrough decoration.

Underline

Draw below text. Configurable: add an underline, or thicken the strokes above.

Insert

Vertical stroke downward between elements. Configurable: line break or insert space.

Join

Vertical stroke upward between elements to merge lines or words.
