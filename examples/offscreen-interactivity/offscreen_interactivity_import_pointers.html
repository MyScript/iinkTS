Interactive Ink Editor - Import pointers

Importing raw pointer events

editor.importPointEvents() replays raw ink input — arrays of x, y, t (timestamp), and p (pressure) values — as if the user had drawn them with a stylus.

This is different from importing JIIX: pointer events bypass recognition and feed directly into the grabber pipeline, making it useful for replaying recorded strokes or injecting synthetic input.
The left panel is pre-loaded with a "hello my friend" stroke set. Edit the JSON directly, then click Import to replay your modified strokes on the canvas.
Use case: automated testing, stroke replay for demos, or migrating raw ink data from another capture device or format.
