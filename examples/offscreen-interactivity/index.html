Interactive Ink Editor — get started

This is the full INTERACTIVEINK editor — the most capable variant. It supports gestures, selection, move, resize, convert, and rich multi-symbol rendering, all driven by a WebSocket connection to the server.

Write, draw shapes, or sketch equations — the editor handles mixed content automatically and keeps the ink interactive after recognition.
A built-in toolbar appears on the canvas. Use it to switch tools, undo/redo, convert, or export without any extra UI code.
