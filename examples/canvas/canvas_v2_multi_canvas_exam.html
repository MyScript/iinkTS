Ink Canvas v2 - Multiple Canvas (Exam)

Multiple canvas — exam form

One InkCanvas instance per input field, not one shared multi-page canvas: this is the pattern to use when a page has several independent handwriting fields (a form, a quiz, a grid) instead of a single free-form canvas.

Each question gets its own small InkCanvas instance, all sharing the same server credentials from the configuration modal but each with its own recognition/rendering config sized for a compact field.
Canvas.load() is not used here: it keeps a single instance per canvas type and destroys the previous one on every call, which breaks with several concurrent INK_V2 instances. Constructing new InkCanvas(fieldEl, options) directly (still a public export) sidesteps that and gives each field a fully independent instance.
"Validate answers" calls canvas.export() on every field's canvas, compares the recognized text against the expected answer, and tallies a score.
