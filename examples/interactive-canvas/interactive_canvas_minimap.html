Interactive Ink Canvas - External Minimap

External Minimap

This example shows how to use the Minimap component in an external container. The minimap is not part of the canvas's DOM tree, but it is still interactive and synchronized with the canvas.

The minimap is created with the Minimap class, which takes the canvas instance and a configuration object as parameters. The minimap is then attached to an external container using the attach method. The minimap will automatically update when the canvas's content changes, and it will also respond to user interactions such as zooming and panning.
