Interactive Ink Canvas — Override default options

Configuration options

All options have sensible defaults. Pass any subset in canvasOptions.configuration to Canvas.load() — unset keys keep their default.

Pen style

penStyle.color"#000000"
any CSS color — #rgb #rgba #rrggbb #rrggbbaa rgb() rgba() hsl() hsla()
Ink stroke color.
penStyle.width2
number (px) — recommended: 1 · 2 · 4 · 8
Stroke width in px.
penStyle.opacity1
0.0 – 1.0
Stroke opacity (optional, defaults to fully opaque).
penStyle.fill"transparent"
any CSS color string
Fill color for closed shapes (optional).

Font style

fontStyle.size"auto"
"auto" · 0.5 · 0.75 · 1
Text size multiplier.
fontStyle.weight"auto"
"auto" · "normal" · "bold"
Text font weight.

Gesture

gesture.underline"draw"
draw · thicken
Action triggered by an underline stroke.
gesture.insert"line-break"
line-break · insert
Action triggered by an insert (caret) stroke.

true · false

Constrain rotation to multiples of this angle (0 = free).

menu.action.enabletrue

menu.context.enabletrue
