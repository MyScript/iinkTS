Math — Context Menu

✏️ Context menu — try it

Draw a circle around any math expression to open the context menu.

Compute
Write √16= or 5+3=, draw a circle around it → Compute numerical result
Function evaluation
Write f(x)=x², draw a circle → Evaluate function, set range −5 to 5
Set variable
Write 2x+5=, draw a circle → Set variable value, enter a number, then Compute
Check diagnostic
Write 1/0=, draw a circle → Check diagnostic to see why computation fails

🔍 Capabilities overview

Also accessible via ≡ → Math → Show Math Capabilities Overview.

✓ ALLOWED
Task can be performed successfully.
⚠ INCOMPLETE_EXPRESSION
Expression needs to be completed.
⚠ TOO_MANY_VARIABLES
Too many undefined variables to solve.
✗ DIVISION_BY_ZERO
Computation leads to division by zero.
✗ NUMBER_OVERFLOW
Result is too large to compute.
✗ INVALID_OPERATION
Invalid mathematical operation.
ℹ NO_VARIABLE / NOT_APPLICABLE
No undefined variables, or task doesn't apply to this expression.
💡 End expressions with = or ? to request a result. Use the scratch-out gesture to erase. Draw a tight circle to trigger the context menu reliably.
