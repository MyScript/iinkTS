Interactive Ink Canvas - Create symbols

Programmatic symbol creation

This example shows how to inject symbols into the canvas from code — without any user drawing — using canvas.createSymbol() and canvas.createSymbols().

The left panel lists each symbol defined in the diagram-with-shape.json fixture. Click Create on a specific symbol or Create all to load the full set at once.
Each symbol is represented as a plain JSON object; you can edit the textarea before creating to experiment with properties such as position, size, type, and style.
Use case: seed the canvas from a database record, reconstruct a saved diagram, or inject server-generated shapes at runtime.
