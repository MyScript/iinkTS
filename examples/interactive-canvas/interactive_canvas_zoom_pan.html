Zoom & Pan

Zoom & Pan API

Control zoom level and viewport position programmatically.

🔍 Zoom

canvas.zoom(level)
Set zoom level (e.g. 1.5 = 150%). Optional centerX/centerY to zoom around a point.
canvas.zoomToFit()
Fit all symbols in the viewport. Pass a symbols array to fit a subset.
canvas.getZoom()
Get the current zoom level as a number.

↔ Pan

canvas.pan(dx, dy)
Shift viewport by dx pixels horizontally and dy pixels vertically.
Zoom and pan also work with mouse wheel (Ctrl+scroll) and Ctrl+drag. Keyboard shortcuts: Ctrl+0 to fit, Ctrl++/Ctrl+- to zoom.
