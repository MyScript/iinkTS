Interactive Ink Canvas — Override menus

Extending built-in menus with custom classes

Any of the four built-in menus (action, tool, style, context) can be replaced by a custom class passed in canvasOptions.override.menu. Extend the base class to keep all existing behavior, then add or modify what you need.

Here, CustomMenuAction extends IIMenuAction to add a Download PNG button (exports the current canvas as a PNG file) and a stroke count badge that updates live on every render cycle.
CustomMenuTool extends IIMenuTool to append a Reset zoom button that snaps the viewport back to 100% with a toast confirmation.
CustomMenuStyle extends IIMenuStyle and injects a restricted configuration: only six brand colors are available, and font controls are hidden — useful for enforcing a design system across users.
