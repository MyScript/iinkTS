Selection API

Selection API

Select symbols programmatically and react to selection changes.

◻ Selection methods

canvas.selectAll()
Select all symbols on the canvas. Emits the selected event.
canvas.unselectAll()
Clear the current selection.
canvas.select(ids)
Select specific symbols by their IDs. Pass an array of symbol ID strings.
canvas.model.symbolsSelected
Array of currently selected TIISymbol objects. Read-only — use select/selectAll to change it.

📡 Selection event

selected
Fires when selection changes. Listen with canvas.event.addSelectedListener(callback). Callback receives the array of selected symbols.

🔍 Zoom to selection

canvas.zoomToFit(symbols)
Pass canvas.model.symbolsSelected to zoom the viewport to fit only the selected symbols.
Switch to the Select tool (toolbar) to interactively select symbols. Then use the API buttons to manipulate the selection programmatically.
