Menu Configuration

Fine-grained menu configuration

Every menu item in the canvas can be individually shown or hidden at runtime via canvas.menu.setConfig() — no reload required. Toggle any switch on the right panel and the change takes effect instantly.

The configuration covers four menus: Action (toolbar buttons: clear, undo/redo, convert, zoom…), Tool (write, erase, select, shape, edge…), Style (color, fill, thickness, font…), and Context (right-click: convert, duplicate, reorder, decorators…).
Sub-menus such as Export formats, Gesture actions, Snap options, Math options, and Decorator types can each be toggled independently.
Use Enable all / Disable all to quickly switch between fully featured and minimal UI, then fine-tune from there for your specific application needs.
