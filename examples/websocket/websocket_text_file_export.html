📄 File export formats

Write text, select a format, then click Export to file — the file downloads immediately.

Word (.docx) — fully editable document, preserves text layout.
HTML — web-ready markup of the recognized text.
PNG / JPEG — raster image of the ink as rendered on the canvas.
Under the hood, editor.export([mimeType]) triggers the recognition engine; the result arrives via the exported event and is converted to a downloadable Blob using FileSaver.js.
