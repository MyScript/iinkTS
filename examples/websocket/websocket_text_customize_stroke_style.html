Websocket Text Styling

🖊️ Stroke styling — three layers

Theme (editor.theme) — global style: ink color, pen width, text font size. Can also define named pen classes (e.g. .greenThickPen) for reuse.

Pen style (editor.penStyle) — inline override for the active stroke only. Takes priority over the theme ink settings.
Pen style classes (editor.penStyleClasses) — references a class name defined inside the theme object (not a CSS class). Disables direct theme selection while active.
-myscript-pen-width is a MyScript-specific property: values range from 0 (hairline) to 5 (very thick), independent of CSS pixels.
The overlay at the bottom shows the exact style object currently applied — useful to copy into your own configuration.
