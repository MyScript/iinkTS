Websocket Text

✍️ Handwritten text recognition

Write naturally on the editor — recognition is continuous and updates in real time as you write.

The recognized text is exported via application/vnd.myscript.jiix and the plain-text label is displayed above.
Use the language selector to switch recognition language on the fly — the editor reloads automatically.
Use Undo / Redo to step through stroke history, and Clear to reset the canvas.
