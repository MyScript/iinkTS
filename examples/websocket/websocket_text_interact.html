🧠 Interactive handwriting exercises

This example shows how to build automated exercises driven by handwriting recognition — the app asks a question, the user writes the answer, and the result is validated in real time via the exported event.

Recognition fires automatically as you write, no submit button needed. The answer is checked as soon as the engine produces a text/plain export.
Use Next question to cycle through the 5 capitals. The editor is cleared automatically between questions.
Pattern applicable to any exercise type: spelling, maths, translation, fill-in-the-blank — just replace the question/answer arrays.
