Interactive Canvas SSR Text Eraser

🧹 Text recognition with eraser

Switch between Pen and Eraser tools using the toolbar buttons. The active tool is highlighted.

Two erase modes are available via text.eraser.erase-precisely: the default mode erases whole words at a stroke, while precise mode erases only the ink segments actually touched by the eraser.
Toggle Erase precisely to switch modes on the fly — the canvas reloads automatically with the new setting.
