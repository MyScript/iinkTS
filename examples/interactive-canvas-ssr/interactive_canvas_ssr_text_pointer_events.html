Pointer events

🖱️ Programmatic pointer events

canvas.importPointEvents(strokes) injects raw stroke data directly — no physical input needed. Useful for replaying recorded sessions, testing, or integrating custom hardware (digitizers, stylus SDKs) that expose raw coordinates.

Each stroke is an object with pointerType ("pen", "mouse", "touch") and a pointers array. Each pointer has x, y (coordinates), t (timestamp in ms), and p (pressure 0–1).
Timestamps must be monotonically increasing within a stroke — gaps between strokes are used by the engine to infer word boundaries.
