No guides

✏️ Text recognition without guides

By default, the canvas displays horizontal guide lines to help users write in a straight line. This example disables them by setting text.guides.enable: false.

Recognition quality is unchanged — the engine does not rely on guides to interpret handwriting. Guides are purely a visual aid for the user.
Removing guides is useful for free-form layouts, custom backgrounds, or when the host UI already provides its own writing lines.
