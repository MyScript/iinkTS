Import math with JIIX

💾 Export & re-import JIIX — resume your work later

JIIX (JSON Interactive Ink eXchange) is the full internal representation: recognized symbols, structure, and the original ink strokes. Exporting it lets you save the exact state of the canvas.

Re-importing the JIIX later fully restores the session — strokes are replayed and recognition re-runs, exactly as if the user had just written it.
Use case: save a math sheet to a database, reload it the next day and continue editing seamlessly.
Click Export JIIX to dump the current content into the JSON panel on the left. You can also paste any JIIX directly into that panel, then click Import to load it into the canvas.
