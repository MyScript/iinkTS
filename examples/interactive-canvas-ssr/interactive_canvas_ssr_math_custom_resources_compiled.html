Custom resources math (pre-compiled)

🏫 Pre-compiled grammar — same restriction, lighter payload

Same goal as the inline grammar example: limit recognition to elementary school math (digits 0–9, + and − only).

The difference: the grammar is compiled and uploaded to the server in advance. The client simply references it by identifier (customGrammarId: 'math-elementary') — no grammar string is sent on every request.
Prefer customGrammarId over customGrammarContent in production: the compiled grammar is faster to load server-side and keeps the configuration payload small.
Try writing 3 + 5 or 12 - 4. Complex symbols like ∫ or √ will not be recognized.
