Styling canvas

🎨 Custom canvas styling

Canvas appearance — pass override.cssClass with your own CSS class name. The canvas root element receives that class, letting you fully control background, cursors, layers, and UI components via CSS.

Ink color — set penStyle.color for the ink drawn during capture, and theme.ink.color for the recognized ink rendered by the engine. Both must match when writing on a dark background.
This example applies my-custom-class (defined in my-custom-classes.css), which sets a photo background and white ink to match.
