Interactive Canvas SSR Math With Graph

📈 Handwritten math → live graph

Write a mathematical expression on the left — functions (y = x²), equations (x² + y² = 25), inequalities… The engine recognizes it and exports it as LaTeX.

The LaTeX is fed directly to Desmos, which plots the corresponding curve on the right in real time.
Write multiple expressions one after another — each is plotted in a different color.
Use Clear to reset both the ink and the graph.
