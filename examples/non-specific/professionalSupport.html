Offscreen Interactivity - Send Data to Support

Collect & send data to support

This example shows how to attach arbitrary key/value data to a WebSocket session using canvas.client.sendToSupport(data). The server acknowledges the message with an ack, which resolves the returned promise.

Add one or more key/value pairs below, then click "Send to support". Each call is queued and resolved in the order it was sent, matching the order the server acknowledges them.
